0.3.0

November 23, 2026 · Full release notes

Definitions support up to 64 endpoints, 22 bounded Roblox value shapes and scoped Instance references. New field types include bounded buffers, maps, tagged unions and compact numeric formats.

Either side can request a reply. Servers can share state updates across players and schedule ordered streams. Clients can pace their batches. Sessions can also report traffic and refusals.

The runtime does less repeated work in encoding, queuing and request tracking while keeping those wire formats intact. The source ZIP includes the Relay Tools CLI, schema checks, TypeScript integration, consumer testing kit and Studio inspector.

Primitive unreliable events can use RR7 frames. Ordered unreliable events use RR8. If you change a schema or transport topology, update both sides together. Upgrade compatibility

0.2.0

October 9, 2026 · Full release notes

Clients gained typed requests. Servers could send to selected players or exclude players from a send. This release also added one-shot listeners, listener readiness, FIFO batches and queues that keep the latest unsent state.

Developers could reuse named shapes, inspect a compiled definition and read bounded diagnostics. 0.2.0 API reference

0.1.0

October 9, 2026 · Full release notes

The first release sent reliable events as native Roblox tuples. A shared schema defined each payload, and the server limited incoming client traffic.
