Relay 0.3.0

Send your first event

Send a number from a Roblox client to its server. You'll define one event, Ping, and see who sent it in Studio's Output window.

Install Relay

Download the 0.3.0 model

Open a baseplate in Studio. In Explorer, right-click ReplicatedStorage, choose Insert from File, and select the downloaded .rbxmx. You should see a ModuleScript named Relay inside ReplicatedStorage.

For type checking, select Workspace and set UseNewLuauTypeSolver to Enabled. The three scripts below use --!strict.

Add the three scripts

In Explorer, create each script with the name, type and location shown. Replace its default contents with the corresponding code. The server and client both require Definition, so they agree on what Ping carries.

DefinitionModuleScript in ReplicatedStorage 
--!strict
local Relay = require(game:GetService("ReplicatedStorage").Relay)
local s = Relay.schema

local definition, definitionError = Relay.define({
	name = "Quickstart",
	version = 1,
	events = {
		Ping = s.clientToServer(1, s.fields(
			{ sequence = s.u32() }
		)),
	},
})

assert(definition, definitionError and definitionError.message)
return definition
ExampleServerScript in ServerScriptService 
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Relay = require(ReplicatedStorage.Relay)
local Definition = require(ReplicatedStorage.Definition)

local serverResult, createServerError = Relay.createServer(Definition, {
	inboundRate = {
		perPlayer = { capacity = 120, refillPerSecond = 60 },
		aggregate = { capacity = 960, refillPerSecond = 480 },
	},
})
local server = assert(serverResult, createServerError and createServerError.message)

local connectionResult, connectError = server.events.Ping:Connect(function(player, sequence)
	print(string.format("Received Ping %d from %s", sequence, player.Name))
end)
assert(connectionResult, connectError and connectError.message)
local started, startError = server:Start()
assert(started, startError and startError.message)
ExampleClientLocalScript in StarterPlayer › StarterPlayerScripts 
--!strict
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Relay = require(ReplicatedStorage:WaitForChild("Relay"))
local Definition = require(ReplicatedStorage:WaitForChild("Definition"))

local clientResult, createClientError = Relay.createClient(Definition, { startupTimeoutSeconds = 10 })
local client = assert(clientResult, createClientError and createClientError.message)

local started, startError = client:Start()
if not started then
	client:Destroy()
	error(startError and startError.message or "Relay client startup failed", 0)
end

local sent, sendError = client.events.Ping:Send(1)
assert(sent, sendError and sendError.message)

Run in Studio

Open the Output window and press Play. Look for this line from the server, with your player name at the end.

Received Ping 1 from <player>

Click Stop to end both sessions. In ExampleClient, change Ping:Send(1) to Ping:Send(2), then press Play again. The server should now print Received Ping 2 with your player name.

To send a message back to a client, see send and receive.
